# Documentación — FarmaSync

Esta carpeta contiene la documentación correspondiente al proyecto FarmaSync y a las diferentes entregas del proyecto integrador de Base de Datos I.

## Entrega 1 — Planteamiento y diseño

La primera entrega aborda el análisis del problema y el diseño inicial de la base de datos.

### Contenido

- **Planteamiento del problema:** descripción de la organización, situación actual, problemática identificada y necesidades que debe resolver el sistema.
- **Requisitos e interrogatorio:** requisitos de información, preguntas que debe responder el sistema, supuestos y decisiones tomadas sobre el dominio.

## Entrega 2 — Implementación

La segunda entrega convierte el diseño en una base de datos real que Funciona.

### Contenido

- **Correcciones de la Entrega 1:** Las observaciones recibidas, incorporadas al diagrama y al esquema.

- **DDL como migraciones:** El esquema completo en scripts.

- **Datos semilla:** Un script de datos ficticios coherentes.
